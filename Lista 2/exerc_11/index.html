Exercício 11

Faça um código em JavaScript que receba, como
dados de entrada, a quantidade de gado.

Calcular e apresentar a quantidade de cabeças de gado
que sobraram depois da divisão ter sido feita entre
os herdeiros, lembrando que cada herdeiro deverá
receber uma quantidade igual de cabeças de gado.

Desconsidere se este valor não for inteiro.

Detalhe: o fazendeiro, antes de falecer, doou
15% das cabeças de gado para a caridade.
